# 智能驾驶数据教程：内容与分享复审

复审日期：2026-11-03。对象：[《数据交付之后，模型怎样真正学会》](../docs/driving-data-learning.html)，面向数据工程初学者。

**结论：在本次检查范围内，修正后未发现阻止分享的问题。** 教程现在可以独立阅读，资料出处集中在末尾，并提供包含离线网页、教学代码与参考结果的[实验包](../docs/downloads/driving-data-learning-labs.zip)。这是一轮 AI 辅助内容复审与实际程序验证，不是独立真人评审、读者学习效果实验或实车验证。

## 内容检查与修正

复审沿“数据身份 → 场景切分 → 采样 → 有效监督 → 参数更新 → 独立验收”检查概念、算例、代码与结论是否一致，同时检查必要解释是否仍依赖外部资料。

| 发现的问题 | 修正后的行为与含义 |
| --- | --- |
| 正文引用 `labs/...`，收件人却拿不到代码 | 提供可下载 ZIP，写明解压后的工作目录；包含全部三个实验与参考结果 |
| “24 个有效目标点”容易被当成 24 个独立标签 | 明确为 6 个有效点重复消费 4 次，共 24 点累计暴露；正文与交互同步 |
| 示例驾驶日期与微秒时间戳不一致 | 统一到 2026-09-01；输入合同示例内部一致 |
| batch、collate、padding、mask、query、CNN 等首次解释不充分 | 在对应机制首次出现处补齐中文含义、作用和必要条件 |
| 教学训练结果容易被读成一般性能优势 | 给出本次实际误差及普通场景代价，强调单个种子、合成数据和适用范围 |
| NumPy 未固定版本 | 将已运行环境固定为 Python 3.13、PyTorch 2.15.0、NumPy 2.5.4，保留跨平台浮点差异说明 |
| 数学程序里一个未用于正文的总体风险计算使用了不一致的尾部比例 | 统一到尾部比例 0.001；总体风险为 1.008；重新运行数学程序并更新参考结果 |

教程保留了几项重要边界：采样比例乘损失权重得到的是系数占比，不等同于实际梯度贡献；非零损失不证明参数已更新；更低的开环轨迹误差不等同于更安全的驾驶；日志对账不能单独证明新增数据导致收益。

## 研究证据复核

本次针对已保留的全文抽取记录复核了四组容易误读的比较。教程末尾保留完整资料清单；此处列出复审关注点。

| 证据 | 核对结果与阅读边界 |
| --- | --- |
| nuPlan 表 III | 开环、闭环非反应式、闭环反应式属于不同评测协议；分数不是安全概率，不把不同列直接排名 |
| EgoStatus 表 1 | EgoMLP 与 BEVPlanner++ 的 0.35 m、碰撞指标及 CCR 数值按对应定义解释；不写成实车事故率 |
| UniAD 表 10 第 3→4 行 | 3 秒 L2 从 1.76 到 1.81 m，同时碰撞指标从 1.39% 到 1.05%；这是推理阶段占用优化的权衡，不是新增数据收益证据 |
| Dataset Cartography 表 2 | WSC 的 ambiguous 子集 87.6±0.6 与随机子集 85.6±0.4 保留三种子背景；这是 NLP 实验，不能直接外推到智能驾驶 |

另通过原始发布网站复核了 [nuPlan 2024 版本身份](https://arxiv.org/abs/2403.04133)与 [Dataset Cartography 的出版记录](https://aclanthology.org/2020.emnlp-main.746/)。部分 PyTorch 官方页面对自动化请求返回 403，本次不把这一状态判为链接失效；相关说明结合已保留的官方资料与实际程序执行核对。

## 尚未建立的结论

尚未进行独立真人试读、屏幕阅读器验收、人工逐页打印验收、微信等客户端的分享卡片实测，也未证明这种教程形式比其他形式更能提升学习效果。合成训练只展示采样、损失和更新的机制，不代表真实自动驾驶系统的泛化或安全能力。

后续最有价值的改进是让一位数据工程初学者只拿到公开链接，完成三个交互与一个代码实验，记录在哪一步需要额外解释；在获得实际反馈前不报告理解率。
