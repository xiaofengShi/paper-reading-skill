# Optional role split

Use multiple agents only when the user explicitly asks for delegation/parallel agents and the host allows it. The default paper read is one coherent reader producing the full atlas.

If requested, split by non-overlapping responsibility: a source reader reconstructs the global path and mechanisms; an experiment reader extracts setups, metrics and results; a verifier checks source anchors and numeric consistency. Merge them into one reader-facing atlas. A reviewer role is relevant only when REVIEW was requested. Never ask several agents to summarize the whole paper independently or let a diagram specialist invent facts without source access.
