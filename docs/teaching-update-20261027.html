具体改动及用途

读者原先容易卡住的位置 本轮改动 验收依据
不知道阅读门槛与读完能做什么 两篇首屏声明适合读者与具体目标；提供第一遍阅读路线 浏览器实际 DOM 可读；旧源可省略这些字段
LoRA 初始化、SVD 子空间公式跳跃 解释为何 A、B 不能同时从零开始；先算二维方向重合，再引出论文度量 初始化梯度经有限差分复核；教学例与论文事实明确区分
LoRA 交互只能改参数预算 改变输入后同时计算 Ax、B(Ax)、W0x、两路相加和合并矩阵输出；预算保留为次级展开项 36 组输入的两条计算路径一致；浏览器键盘验证正向、零修正、反向与复位
ResNet 直接进入 Jacobian 从标量链式法则与 ReLU 门控算出 3.6，再提供可选矩阵扩展；改变 shortcut 的迁移题得到 0.9 单独复算与 AI 审核一致；没有把局部导数外推为整体训练保证
附录像任务和数字清单 LoRA 用 DART 串起输入、生成与测量；ResNet 用检测框 refinement 串起输入、操作、输出与指标 与指定版本附录及对应结果表核对
全量数据打断主要论证 使用原生 details 保留完整表格和协议；关键限制、比较条件与反例留在正文 实际键盘展开；表格与公式正常渲染，无脚本也有原生展开结构
检查题偏向复述 新增改变维度、预算或 shortcut 的迁移题 LoRA 共 4 题、ResNet 共 5 题；答案披露是学习辅助，不是理解分数
