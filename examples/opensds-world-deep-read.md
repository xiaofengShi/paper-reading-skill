# OpenDS-World 深读：把深度搜索 Agent 放回真实开放网页

深读对象：Deep Search in Real-World Web Environments（arXiv 2610.30181v1，HKUST(GZ) 牵头、14 家机构 25 位作者）。这是一篇基准论文：它构造了一个任务宇宙（200 道题、787 个标注证据条目），再用统一的工具环境与执行协议去测 12 个前沿模型，测量声明是"当前 Agent 在真实开放网页中做端到端深度搜索的能力远未成熟"。下文按"全景—任务—构建—评测协议—实验—综合"展开，所有关键数字都带原文定位（默认隐藏，右上角"显示原文定位"可展开）。

## 01 全景：这篇论文在做什么

现有 Deep Search 评测大多停留在静态检索或多轮问答：语料固定、答案可以直接"查到"。真实网页不是这样——信息散布在不同网站、不同模态（文/图/音/视频）、不同文件格式（HTML、PDF、Parquet、ZIP……），而且有些证据必须通过交互（导航、填参数、拖动时间轴、下载文件）才能拿到（PDF §1）。OpenDS-World 的做法是：把"证据获取过程本身"作为被测对象。每道题从一段真实视频出发，Agent 要自己在开放网页里搜索、访问、处理并串联证据，最终给出唯一事实性答案（PDF §2.1.1）。

一个贯穿全文的反直觉数字：人类不是安全网。1000 次独立人类尝试的总体正确率只有 21.10%，42.5% 的题没有任何一位人类求解者答对（PDF §2.3.2）。这个基准对人和模型都难，而它的难度标定恰恰来自这批人类数据。

## 02 任务定义：深度搜索到底难在哪

OpenDS 的任务定义本身只有一句话：给定问题和初始线索，Agent 在开放网页中自主完成多步证据搜索与推理，输出唯一可验证的事实答案（PDF §2.1.1）。真正的信息量在"开放网页"被拆成的三个正交属性上——它们分别刻画信息的表现形式、组织结构、获取方式（PDF §2.1.2）：

- **多模态（Diverse Modalities）**：证据可能在网页正文、图片、语音或多媒体资源里，同一题的不同阶段可能依赖不同模态；
- **异构格式（Heterogeneous Formats）**：同为"文本信息"，可能装在 HTML、PDF、XML、Parquet 里，解析与处理方式完全不同；
- **交互式访问（Interactive Access Requirements）**：有些证据无法直接检索到，必须导航、输入参数、时间索引、操作图形界面、结构化查询或下载文件后才能获得。

## 06 综合评述

把机制与证据放回一起看，这篇论文的测量声明由三层支撑咬合：**任务定义**把"证据获取"从检索评测的背景变成了前景（§2.1）；**构建流水线**用"视频锚点 + 正向证据扩展 + 反向问题反演 + 独立验证 + 人类定标"保证 200 个任务既真实又可验证（§2.2–2.3）；**统一协议**用相同工具与预算把 12 个模型放进同一环境，过程性指标（工具分布、终止原因、失败恢复、预算触顶）让"为什么错"变得可分析（§3）。

结果的边界也要读准。它证明的是"在 200 道经人工验证、答案唯一的多跳事实问题上"的能力分布：题目不追求知识前沿而追求证据获取复杂度；活网页存在漂移风险，论文用归档锚点视频控制输入端，但证据链中段仍依赖真实网页的存续（附录 C.1.2 只覆盖输入视频）；裁判为单模型参考答案判定，语义等价的边界案例可能被严格规则放大（附录 C.4）。另外 12 模型的排名是特定预算（3600s/100 次）下的快照：Qwen3.8-Flash 80% 的题打满调用上限，它的 12.0% 更像"预算内无法完成搜索"，而非能力上限（§3.6）。

**与读者研究方向的关联（读者推断，非论文内容）**：如果你在做检索 Agent / Agentic RAG / 学术检索方向，这篇基准有三处可直接借用——其一，"正向铺证据链、反向反演出题"的构造方法天然防作弊（单线索搜不出答案），可迁移到学术信息检索类基准的题目生成；其二，七类访问方式分类法（观察/导航/参数/时间索引/图形操作/声明式查询/文件转移）是一个现成的"证据获取难度"标注维度，可以加到任何 RAG 评测的任务元数据里；其三，"资源消耗与正确率脱钩"的结论提示检索 Agent 的训练目标（例如后训练中的过程奖励）应显式覆盖停止决策与信源选择，而不只是最终答案正确——这与论文结论呼应的"长程搜索与递归自我改进"（§5、附录 E）正是 Agent 方向的下一批问题。多模态侧，音频证据覆盖随难度上升（附录 B.5）而多数模型音频准确率明显偏低（附录 D.2），是视听理解进入检索链路的一个可做的缺口。

最后用论文自己的话收束：OpenDS-World 提供的是"研究长程搜索与递归自我改进的具体地基"，目标是用它做出"能在真实开放网页环境中可靠地发现、访问并整合证据的 Agent"（PDF §5）。
